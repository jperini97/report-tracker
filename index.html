About this mockup. This page is a static file — perfect for GitHub Pages — and every entry is saved in your own browser's local storage, not a shared database. That means if you and a colleague both open the published link, you'll each see and edit your own separate copy, not the same list. It's a faithful preview of the layout and interactions, not yet a multi-person tool.

To make entries actually shared across the company, this front end would need to talk to a small backend — a Google Sheet, Airtable base, or lightweight database behind a form submit. Happy to help wire that up when you're ready.
